# InfluxDesk v1.0.0

首个非预发布版本，面向 InfluxDB 1.x / InfluxQL 的中文桌面工作台。

## 下载选择

- `InfluxDesk-1.0.0-win10-x64-installer.exe`：Windows 10 x64 NSIS 安装器，携带 Microsoft WebView2 bootstrapper；推荐 Windows 10 22H2。
- `InfluxDesk-1.0.0-win11-x64-installer.msi`：Windows 11 x64 WiX MSI，要求 build 22000+ 且系统已安装 Microsoft Edge WebView2 Evergreen Runtime。
- `InfluxDesk-1.0.0-macos-universal.dmg`：macOS 12+ 安装镜像，同时支持 Apple Silicon 和 Intel。
- `InfluxDesk-1.0.0-macos-universal.zip`：macOS 12+ universal `.app` 压缩包。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。

## 发布边界

本版本由 GitHub 托管的 Windows 与 macOS 原生 runner 构建并检查包结构、版本、架构和校验和，但仓库当前未配置商业代码签名凭据：

- Windows EXE/MSI 未做 Authenticode 签名，SmartScreen 或安装器会显示未知发布者。
- macOS `.app` 仅做 ad-hoc 签名，未提交 Apple 公证，也未 stapling；Gatekeeper 可能阻止直接打开。
- Win10 NSIS 与 Win11 MSI 使用不同的安装器升级机制；切换安装包前应先卸载已有版本，本次不支持二者之间自动覆盖升级。
- Windows 10/11 干净 VM 的安装、升级、卸载与 WebView2 异常场景，以及真实 Apple Silicon/Intel 设备上的启动、Keychain、Gatekeeper 验收，仍需后续完成。

请只从本仓库 Releases 下载，并先核对 `SHA256SUMS.txt`。浏览器测试不等同于 Windows/macOS 原生运行验收。
